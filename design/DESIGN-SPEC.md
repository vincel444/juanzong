# 卷宗 v2 界面设计方案 · 摘要

> 高保真可交互原型：`design/ui-proposal.html`（双击或预览打开，全部交互可点击体验）

## 设计策略（为什么这样设计）
1. **沿用主流 AI 对话心智模型**（左栏 + 对话流 + 底部输入），用户零学习成本
2. **差异化放在"信任"上**：右侧常驻溯源面板 + 正文句子级三色标注——把"敢不敢信"变成看得见的证据
3. **三档路由透明化**：档位徽章、时延、token 全部如实展示，呼应"工程扎实"的答辩口径
4. **视觉与 PPT 同源**（#0F172A 深蓝体系），参赛作品形成统一品牌记忆

## Design Tokens
| 类别 | 值 |
|---|---|
| 底色 | `#0F172A` 全局 / `#1E293B` 面板 / `#243147` 嵌套 |
| 文本 | `#F1F5F9` 主 / `#94A3B8` 次 / `#7C8BA1` 弱（对深底对比 15.9 / 7.5 / 4.7，均达 AA）|
| 品牌 | 蓝 `#3B82F6`（强调）/ `#2563EB`（按钮底，白字 5.2:1）/ 青 `#06B6D4`（focus/accent）|
| 语义 | 已溯源 `#34D399` / 部分 `#FBBF24` / 未溯源 `#F87171` |
| 字体 | UI 微软雅黑 UI；数字/时延 JetBrains Mono；14px 正文 / 12.5 辅助 / 11 标签 |
| 间距/圆角 | 4px 基数；圆角 6 / 10 / 14px |

## 关键组件
- **档位徽章**：深档=蓝底白字实心、中档=蓝描边、轻档=青描边（一眼分辨成本差异）
- **思考过程**：`<details>` 折叠卡，虚线边框 + 青色箭头，流式中带打字光标
- **溯源高亮**：句子级底色+底边线；点击高亮句 → 右栏对应引用卡滚动定位并闪烁
- **运行状态条**：首字时延 / 总时延 / token / 溯源命中率，等宽数字
- **输入路由预测**：输入实时提示"将由 4B 深档审阅（约 40s）"——把等待预期前置，深档 40s 不再像卡死
- **快捷提问 chips**：4 条演示问题一键填入

## 无障碍（WCAG AA）
- 全部文本/背景组合对比度 ≥ 4.5:1（含弱化文字 4.7:1）
- `:focus-visible` 青色 2px 外框；按钮 ≥ 40px 触达高度
- `prefers-reduced-motion` 时关闭全部动画
- 语义化标签 + aria-pressed / aria-label

## 落地路径
- **轻改**：Gradio `gr.Blocks(theme=...)` + 自定义 CSS 注入 tokens（1 天内，保留现有逻辑）
- **完整版**：桌面壳 `desktop.py` 的 WebView 直接加载静态前端（HTML/JS），用 `pywebview.api` 桥接现有 Python 后端——原型即骨架
