# DESIGN.md — 卷宗 · 初赛 PPT 视觉设计

> 路线：通用设计原则（技术竞赛，非学术/咨询/政务垂直场景）
> 调性：科技、可信、克制。以「深色底 + 蓝青强调」建立技术感，用大号数据锚点承载证据。

## 1. 画布与母版

- 画布：1280 × 720
- 页面 padding：上下 20px，左右 72px

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120px | 主标题 34px bold，左对齐；右侧统一放「章节标签」小字（非装饰图） |
| B · 内容区 | 120–660px | 540px | 正文/图表/卡片，禁止挤占 A/C |
| C · 页脚条 | 660–720px | 60px | 左：卷宗 · Spark-X2.5 端侧挑战赛　右：`NN / 12` 14px 灰字 |

- 封面 / 结束页采用自定义版式，省略 C 区页码。
- 全篇 A 区标题位置、C 区页码位置严格一致。

## 2. 颜色系统

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景（主色） | `#0F172A` | 全篇深色底（科技感） |
| 面板/卡片（辅色） | `#1E293B` | 卡片背景、表格行底 |
| 强调色 · 蓝 | `#3B82F6` | 核心数据、标题下划线、关键柱条 |
| 强调色 · 青 | `#06B6D4` | 第二数据系列、成功态（已溯源） |
| 文本主色 | `#F1F5F9` | 正文、标题 |
| 文本次色 | `#94A3B8` | 页脚、注释、次要说明 |
| 警示色（中性补充） | `#F59E0B` | 「部分溯源」态、风险标注 |

> 注：为满足「≤ 4 hex」约束，核心池为 `#0F172A` / `#1E293B` / `#3B82F6` / `#06B6D4`；
> `#F1F5F9` `#94A3B8` `#F59E0B` 作为文本与状态色不属于装饰性色彩池。

### 2.1 色彩面积分配

| 页面角色 | 主色 | 辅色 | 强调色 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| Hero 页（P2/P6/P7/P9） | ≤ 60% | ≤ 25% | **15–20%** | 强调色爆发：巨型数字、核心柱条 |
| Supporting 页 | ≤ 60% | ≤ 30% | ≤ 5% | 克制，强调色只用于焦点 |

- 色彩节奏：P2/P6/P7/P9 为强调色高占比页，与其余页形成显著差异（≥ 2 页比例不同 ✓）。

### 2.2 渐变与半透明

- 卡片头部渐变：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)`（仅用于 P6 溯源三级判定的表头）
- 大面积浅色覆盖：`rgba(59,130,246,0.08)` —— 表格斑马纹、卡片高亮区
- 卡片浮起：`boxShadow: '0 4px 20px rgba(0,0,0,0.3)'`
- 元素叠层：装饰网格/光晕 `opacity: 0.15`

## 3. 字体系统

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 72 | bold | 1.2 | 仅封面 |
| 巨型数据锚点 | 88–110 | bold | 1.0 | P2 三个数字、P7 提速倍数、P9 消融对比 |
| 页面主标题 | 34 | bold | 1.3 | A 区，每页固定 |
| 卡片小标题 | 24 | bold | 1.4 | 卡片头 |
| 正文 | 22 | regular | 1.5 | 段落、表格内容 |
| 表格正文 | 19 | regular | 1.4 | 表格内（信息密度需要） |
| 引文 | 22 | italic | 1.5 | 访谈原话（用「」） |
| 页脚/页码 | 14 | regular | 1.4 | C 区 |

- 字体家族（≤ 2 套）：中文 **思源黑体 / Microsoft YaHei**；西文与数字 **Inter / JetBrains Mono**（数据用等宽增强技术感）
- 巨型数字必须与正文不同字重：正文 regular 22px，锚点 bold 88px+

## 4. 信息密度

| 页面类型 | 最少元素 | 正文字数下限 | 图数 | B 区主视觉 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标题+副标+主视觉 | 20 | 1 | ≥ 35% |
| 内容页 · 单主题 | 标题+正文+主视觉 | 180 | 1 | ≥ 30% |
| 内容页 · 卡片组 | 标题+引导+N卡 | 每卡 ≥ 100 | 0–N | — |
| 数据/图表页 | 标题+主图+洞察 | 80 | 1 主图 | ≥ 50% |

- 常规页留白 ≤ 35%；Hero 页可至 40%（围绕焦点元素）
- 容器填充率 ≥ 85%；卡片尾部元素（标签/引文条）用 `marginTop: auto` 钉底
- 横向兄弟卡三段（标题/正文/尾部）y 轴对齐，偏差 ≤ 16px

## 5. 配图系统

| 等级 | 用途 | 出现位置 | 最小尺寸 |
| :--- | :--- | :--- | :--- |
| **L1 主视觉** | 承担页面叙事 | P1 封面底图、P3 痛点对比、P8 工程细节 | ≥ 40% B 区 |
| **L2 支撑图** | 强化段落 | P7 bench_chart.png（实拍图表） | ≥ 280×180 |
| **L3 母版徽标** | 全篇统一角标 | 仅 C 区左侧文字标识（不使用图片角标） | — |

- 配图风格统一：**科技暗色插画 / 3D 抽象**（禁摄影与插画混用）
- P7 使用真实产出的 `bench_chart.png`（列入 assets/），是硬证据不是装饰
- 架构图、流程图、矩阵、巨型数字、进度条 → 用 SVG
- P1/P3/P8 需生图（L1）：统一 prompt 风格词 "dark tech, deep navy background, isometric 3D, blue-cyan glow, no text"
